# Proposal: Coastal editorial visual redesign

## Why
The current site has SEO improvements but still presents the original visual treatment. A guest should immediately perceive Hotel Haven as a calm, credible Andaman stay rather than a generic template.

## What Changes
- Replace the current bright multi-accent system with a restrained coastal palette.
- Improve type hierarchy, spacing rhythm, navigation clarity, buttons, cards, forms, and section transitions.
- Make the homepage hero more premium and photography-led without changing its factual content.
- Make room and amenity cards easier to scan and compare.
- Improve mobile navigation, responsive grids, focus states, and touch targets.
- Preserve all existing page routes, booking controls, API hooks, SEO metadata, structured data, and factual copy.

## Capabilities
### Modified Capabilities
- Visual presentation of every HTML page using the shared stylesheet.
- Homepage hierarchy and perceived brand quality.
- Responsive behavior across desktop and mobile widths.

## Breaking Changes
None intended. No route, form ID, API endpoint, schema block, or content fact changes.

## Rollback
Revert the redesign commit; the previous SEO branch remains the parent commit.
